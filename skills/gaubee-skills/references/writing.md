## 文体基调（默认，不问）

changelog 风格：客观、直观、通俗且准确，无晦涩词汇和比喻。按工作流分节，每节陈述「做了什么/为什么/可观察行为」，数字直接给；不写背景弧、不设悬念、不写"未来可期"式收尾——写完就停。

平实 ≠ 稀释：平实是降低读者的**处理成本**，不是降低**信息量**。正确形态三件套同时成立：常用词汇 + 完整事实 + 结构化呈现。删事实换通俗是 dumbing-down，比工程腔更早被打回。

语域禁令：①成语/四字格装饰（「一眼看清」类）；②口语拟态（把「不阻断」写成「不拦人」）；③散文式枚举（「一是…二是…」→ 用列表）；④破折号全文预算 ≤1 个。

## 结构模板（信号日报）

1. **冷开一句**（D1）：昨天分量最重的一件事，直陈。禁止暖场、禁止"本文将"、禁止标题复述。
2. **工作流小节 ×N**：每条 = 谁 + 做了什么（读提交消息归纳，可跨仓库归组）+ 关键证据（commit 原文短语或数字）。小节标题 = 收益动作短语（D15：命名读者世界的改善，不是对象清单）；正文首句 = 事实层（数字住在这）。
3. **其余信号**：星标/X/依赖各一句话带过。修复与小事件默认一句话。
4. 版面占比 ≈ 决策价值：大事件多写，小事件一句话，无事件一行带过。

## 句级法则（起草时生效，精选）

- **一句一职**（D2）：一句话只干一件事；一段只承载一个意图。
- **长句+短钉**（D3）：让长句跑完推理，再用一句短陈述钉住；禁止全文口号化或无喘息长句串。
- **数字优先于形容词**（D6）：强大/优雅/显著站立的地方，放版本号/耗时/计数/提交号。形容词只能在无测量处出现一次，且是挣来的。
- **事实强度天花板**（D7）：一次观察≠稳定复现；性能声明带基线，否则不发。
- **归纳词 gate**（D8）：「本质上是」「核心在于」只能出现在机制讲完之后，且必须跟一个可核查的归约；否则删词留句。
- **推测标注**（D9）：未验证的判断用「也许/假设」+ 推理，或移出正文。
- **边界结论**（D10）：写「什么条件下值得用/会失效」，不写「最强/完胜」。
- **比喻预算**（D13）：全文至多一个，且只能出现在机制讲完后的定位句。主菜/赌注/接缝类行文比喻一律清除。
- **专有名词预算**（D14）：内部代号首次出现必须大白话释义；API/包名/错误码是对象，照用。判据：没打开过仓库的读者能读懂每个价值句。
- **抽象阶梯**（D15）：小节标题 = 收益动作短语（「提醒按需展开」级），不是对象清单（「apply 证据」级打回）；正文 = 事实层。层级错位是 AI 味的第一破绽。
- **情绪句预算**（D12）：全文至多一句，冷句（"It's done." 级），不许感叹号堆叠。

## 修订门（日报快版，按序；前关不过后关不开）

R1 对账：事实只来自 changes/history/脚本输出；数字必须来自脚本且算术自洽（口径写明：净值还是增量）。
R2 追责：每句强断言问——谁观察的、在什么上、适用范围？无源 → 删或降级为假设。
R3 结构：每段问四问（比上一段多做了什么/删了会坏什么/是否两职/是否偏离开头承诺）。段落 ≤240 字（剔除代码块与链接目标）。
R4 机制：只换名字复述 changelog 条目 = 不合格；要说清怎么发生、何时失效。
R5 查簇：AI-tell 按**密度**定罪（约 200 字内 ≥2 例同款才是罪）。跑 `node scripts/ai-tone-metrics.mjs`（lint reports/daily/*.md，RED 清零才放行；全绿 ≠ 不 AI，回归 craft 层逐条比对）。
R6 朗读：出声读一遍。修复靠重组句子，不靠换连接词。

## AI-tell 清单（常见族）

- 「不仅…还」「既…又」两半不加信息 → 砍成单句直陈。
- 四字滥调（极致/无缝/赋能/保驾护航）无测量支撑 → 删。
- 的链（的X的Y的Z）、主干被「在…背景下」压后 → 主语动词提前。
- 凑三项、否定式排比、无尺度「从 X 到 Y」→ 删。
- 暖场句、预告式写作、舞台式开场、元话语（「值得强调的是」）、假装收尾的泛化积极结尾 → 删。
- 意义膨胀：一次发版 ≠ 时代转折；无主权威（「业内普遍认为」）→ 删。
- 同义词漂移：一个概念全篇一个词。
- 反"表演人类"：不许加假错字、emoji、网语、 borrowed 粗口。

## 反模式（看到即打回）

1. 只写「新增了 X」不写为什么需要 X。
2. 形容词多于数字与代码块。
3. 读完是死路（没有下一步出口）。
4. 标题/摘要用自造词或架构隐喻代替读者可辨认的事实。
5. 把「通俗」做成「白痴文」（砍事实换语感）。
6. 自我标榜（「诚实的限制清单」「不是营销数字」）——读者没质疑过，辩护显心虚。

## 事实与口径（定稿前单独过一遍）

数字全部能指到源且算术自洽；第三方版本回上游 CHANGELOG 核实（不转述转手材料）；「新增 N」区分净值与增量；专有名词先 grep 项目词汇源再判断是不是自造比喻；术语用项目自己的词（比如 opendweb 的「走查」「终审」是它提案里的真词汇，照用）。
