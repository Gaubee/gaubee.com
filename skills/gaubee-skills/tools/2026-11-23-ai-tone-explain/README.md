# ai-tone-explain — 某个指标到底匹配了什么，并标出疑似误报

## 是什么

打印每个命中的**原文片段**（前后带上下文），并对疑似误报打标记。比 `ai-tone-locate` 更细：
后者只按句列命中，本工具精确到片段，还能判断「这个『像』是不是复合词的一部分」。

## 解决什么

2026-11-23 实证：`ai-tone-metrics` 报「比喻(明喻) 2 / budget 1 RED」，我怎么也找不到两个比喻。
根因是我把「图片模型」写成「图**像**模型」——`图像` 里的「像」加上后面的「一样」正好命中
`/（像|…）[^。]{2,24}(一样|…)/`。它不是比喻，是复合词的一部分。

当时 `ai-tone-locate` 只覆盖顿号、破折号、提示语几项，不含比喻，只能靠人猜。
本工具补上这条：命中起点落在 `图像/录像/影像/肖像/偶像/想象/好像/相像/像素/雕像/镜像`
这类复合词里时，标「疑似误报」。

## 怎么跑

```bash
bun tools/2026-11-23-ai-tone-explain/ai-tone-explain.ts reports/daily/2026-11-22.md --metric 比喻
bun tools/2026-11-23-ai-tone-explain/ai-tone-explain.ts reports/daily/2026-11-19.md
```

退出码：0 = 有命中并已解释；1 = 该指标无命中；2 = 用法错误。只读。

## 真实示例输出

用夹具（一条误报、一条真比喻、一条真误报）：

```text
simile-fixture.md：3 行行文，命中 3 处

[△ 疑似误报] 比喻(明喻)  L4
    …图【像模型把每张图都切成一样】大的方块。…
    命中起点落在复合词「图像」里的「像」，不是比喻

[✗ 需改] 比喻(明喻)  L6
    …这就【像把一本书撕成一样】大的纸片。…

其中 2 处疑似误报、1 处需要改。
```

真实日报上（2026-11-19）它报出 `顿号罗列≥3` 命中 1 处，与人工核对一致。

## 判读建议

- 「疑似误报」不是让你无视：它提示的是「换掉这个词就行」，不必推翻整句。
- 「✗ 需改」才是真的比喻或并列，按 `references/writing.md` 重写。
- X 日报（`*-x.md`）正文全是 HTML 卡片，扫描行文为 0 是正常的——它的告警在译者笔下，不在成品里。
- 它不复制 metrics 的阈值：判定权仍在 `ai-tone-metrics`，本工具只负责解释。
