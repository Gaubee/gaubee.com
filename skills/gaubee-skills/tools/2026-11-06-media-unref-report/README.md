# media-unref-report — 已入卷但无人引用的媒体盘点

## 是什么

反方向的存储盘点：`x-media-audit` 管「引用了但没入卷」（断链）与 staging 孤儿，本工具管「入了 manifest 但站点没有任何内容引用」的对象，按月与体积汇总，并列出最大的若干项。

## 解决什么

媒体卷是 append-only，历史残留（视频重做 HLS 后的旧 mp4、重生成的旧 poster、改键残留）不会自动消失，也不该被删除，但**占着远端存储**。R2 水位与「单月补丁 >500MB 要不要接外置存储」这类决策需要这个数字，此前只能靠猜。

## 怎么跑

```bash
bun tools/2026-11-06-media-unref-report/media-unref-report.ts --top 5
bun tools/2026-11-06-media-unref-report/media-unref-report.ts --json
```

退出码：0 正常（只报告不判罚）；1 数据缺失。纯本地只读。

## 判读

- 残留率 1.2%，量级健康；最大的四项都是 HLS 化之后被 `.m3u8` 取代的旧 `-video.mp4`——正是追溯工程的预期副产物。
- 「引用」判定：同一推文 id 的 playlist 被引用时，其 `.segNNNN.ts` 视为已引用（段由 playlist 隐式引用），否则 3800+ 段都会误报成未引用。
