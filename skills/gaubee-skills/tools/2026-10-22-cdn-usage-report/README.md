# cdn-usage-report — cdn-media 用量与增长报告（R2 决策支持）

## 是什么

一条命令出齐 cdn-media 的容量决策数据，数据源全部本地（`cdn-media/manifest/` 各代 manifest + current.json），零网络：

- 最新代按月统计：对象数 / 字节 / 分段与媒体计数（字节降序）
- 最近一次补丁增量：与上一代 manifest 逐键 diff，按月列新增
- 代际趋势：保留的每一代（最近 10 代）的总对象数与总字节，标出单代最大增量
- 水位建议：最近补丁单月 >500MB（runbook 水位）即提示评估外置存储（R2）

`--json` 输出机器可读。

## 解决什么

runbook 要求「单月补丁 >500MB 时在总结里提示 kzf 关注外置存储」，但此前没有工具把「现在多大、涨多快、哪个月涨的」一次说清。2026-10-21 单日补丁 1.57GB（HLS 存量回填）后，这类判断需要数据而不是印象。

## 怎么跑

```bash
bun tools/2026-10-22-cdn-usage-report/cdn-usage-report.ts          # 人读
bun tools/2026-10-22-cdn-usage-report/cdn-usage-report.ts --json   # 机器可读
```

零第三方依赖，零网络，秒级退出。`GAUBEE_CDN_REPO` 可覆盖媒体仓路径。

## 真实示例输出（2026-10-22，gen 16）

```

  2026-05    725 对象   588.6 MB（分段 699 / 媒体 26）
  2026-09   1072 对象   450.7 MB（分段 887 / 媒体 185）
  ...

  2026-10  +38 对象  +39.8 MB

  gen-14   4379 对象    3.66 GB （+10.1 MB）

```
