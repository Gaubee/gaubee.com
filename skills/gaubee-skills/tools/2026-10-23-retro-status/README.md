# retro-status — HLS 追溯工程完成度报告

## 是什么

只读统计 2026-10-20 开工的存量视频 HLS 追溯工程进度：全库视频条目里已 HLS 化 / 仍单文件 mp4 / 剩余候选 / 无增益记录的分布，剩余候选按月列出（对应未来随升级产生的待打包流量），并给出续跑命令。

## 解决什么

追溯是长工程（332 候选起步），cron 每天只处理一小批，没有一个一眼看清「还剩多少、值不值得继续」的视图，每次都要现场拼 grep。本工具把完成度固化成一条命令，供「宣布追平」或「继续挂批」做决策。

## 怎么跑

```bash
bun tools/2026-10-23-retro-status/retro-status.ts
```

## 真实输出（2026-10-23 首跑，exit 0）

```text
视频条目 1208｜已 HLS 化 120（9.9%）｜仍单文件 mp4 1088
剩余候选 3（<720p 且未证实无增益）｜无增益记录 215｜>=$720p 单文件 870
剩余按月（待打包流量随升级产生）：
  2026-08  2 条
  2017-12  1 条
续跑：bun tools/2026-10-20-video-retro-hd/video-retro-hd.ts --until 23:59 --no-render
```

## 判读

- 「已 HLS 化 120」含夜间追溯批次 + 每日新增视频的直接 HLS 化；候选从 332 收敛到 **3**，工程实质追平。
- 剩余 3 条分散在 2026-08（2）与 2017-12（1），下次 cron 顺手 `--until 23:59` 一批即可清零。
- 1088 条单文件里 870 条 ≥720p（无增益空间，不追）、215 条已实证无增益（记录在案，不重试）。
