# star-timeline — 星标时间线（每日新增与累计，权威口径）

## 是什么

按 `starred_at` 的本地日聚合星标，输出区间内每天的新增清单与**期末累计数**。日报里「新增 N（总数 M）」的 M 直接抄它，不再心算。

## 解决什么

2026-11-04 补跑四条日报时，「总数」靠心算写成 1730/1738/1739，实际应是 1731/1739/1740——三份都少一位，事后靠 python 重算才发现并回改。这类错误的根源是「今天的抓取数」不等于「报告日收盘累计数」，两个口径混用就必错。本工具固化前者无关、只按 starred_at 精确累计的口径。

## 怎么跑

```bash
bun tools/2026-11-05-star-timeline/star-timeline.ts --from 2026-10-31 --to 2026-11-05
bun tools/2026-11-05-star-timeline/star-timeline.ts --days 14
```

## 真实示例输出（2026-11-05，exit 0）

```text
星标时间线（2026-10-31 ~ 2026-11-05，全集 1749 条）
  2026-10-31  +1  累计 1731  wangzan101/Mika
  2026-11-01  +8  累计 1739  patch-gg/pixelfx、nolly-studio/cult-ui、…
  2026-11-02  +1  累计 1740  paper-design/shaders
  2026-11-03  +8  累计 1748  yetone/alma-relay、wquguru/cicada、…
  2026-11-04  +1  累计 1749  songloft-org/songloft
  2026-11-05   0  累计 1749
区间新增 19，期末累计 1749
```

## 用法建议

写日报的星标节时，先跑本工具取当天行的「累计」作为「总数」，新增条数取该行「+N」——两者就都不会漂。
