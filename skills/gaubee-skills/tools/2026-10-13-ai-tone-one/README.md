# ai-tone-one — ai-tone 单文件体检

## 是什么
`scripts/ai-tone-metrics.mjs` 的单文件 wrapper：只输出指定报告的指标段，并按原脚本
口径（行尾 RED/YELLOW/LOW = 超标；无标记 = 阈值内）给出该文件的通过与否与退出码。
对原脚本零改动零语义漂移（bun 直接跑 .mjs）。

## 解决什么
2026-10-13 实证：原脚本没有参数处理，永远全目录扫描——每日 cron 写完一份日报后
想看「这一份」的体检结论，得在 200+ 份历史报告、上千行输出里自己 awk。本工具一行
出结论、退出码可直接接门禁（`&& 发布`）。

## 怎么跑
```bash
bun tools/2026-10-13-ai-tone-one/ai-tone-one.ts reports/daily/2026-10-12.md
```
退出码：0 = 全部指标在阈值内；1 = 有 RED/YELLOW/LOW 行；2 = 用法错误。

## 真实示例输出（2026-10-13 实跑）
```
2026-10-12.md
  顿号罗列≥3 1.50/0.7k
  （其余 11 项 0.00）

✓ 2026-10-12.md: 全部指标在阈值内   （exit 0）
```
对照（历史文件确有 YELLOW 时）：`2026-10-06-x.md → ✗ 1 项超标（exit 1）`。

## 提示
「顿号罗列≥3 1.50/0.7k」这类无标记行在阈值内，不必处理；定稿约束仍为 RED 清零
（见 cron 第 5 步），本工具的退出码即该约束的单文件形态。
