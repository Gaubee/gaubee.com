# cron-day-briefing — 每日维护开工面板

## 是什么
管道开工时的一次性只读简报：今天几号星期几、YESTERDAY 是哪天、周一专属步骤
（周报/staging 清理）今天是否该跑、近 3 天「changes@抓取日 → 日报@报告日」
对照表（哪些源已抓、哪些日报已生成/缺失）。

## 解决什么
2026-10-18（周日）实证：cron 运行把周日误当周一——提前生成了「今天」的 X 日报
（违反 T-1）、GitHub 日报日期写错、误跑周报。根因是开工时不核对日期与星期。
本工具把「今天是哪天、今天该跑什么」变成开工第一眼的确定性输出。

## 怎么跑
```bash
bun tools/2026-10-18-cron-day-briefing/cron-day-briefing.ts
```
建议位置：管道第 0 步环境门之后。退出码恒 0（简报性质，非门禁）。

## 真实示例输出（2026-10-18 实跑，周日）
```
今天：2026-10-18（周日）　YESTERDAY：2026-10-17
周一专属步骤：无（今天不跑周报/staging 清理）
提醒：日报只写 YESTERDAY（T-1），今天（还没过完）绝不出报告。

近 3 天对照（changes@抓取日 → 应有日报@报告日）：
  changes@2026-10-16（github-stars,...）→ 日报@2026-10-15：GH✓ X✓
  changes@2026-10-17（github-stars,...）→ 日报@2026-10-16：GH✓ X✓
  changes@2026-10-18（github-stars,...）→ 日报@2026-10-17：GH✓ X✓
```
