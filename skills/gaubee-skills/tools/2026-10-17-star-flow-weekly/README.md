# star-flow-weekly — 星标兴趣周流向

## 是什么
把过去 N 天的星标按 taxonomy 分类（以 catalog.md 的脚本落位为准）聚合，输出
「分类 × 增量排行 + 逐颗明细（带行为日期）」。窗口缺省最近 7 天，周一覆盖上一个
完整周，供周报「主题聚类」直接引用；未分类余量单独提示。

## 解决什么
周一写周报时「本周兴趣流向」靠人肉翻 7 天 skeleton 逐颗归类。本工具一次聚合，
分类计数与明细即取即用（2026-10-17 首跑：3 天窗口 9 颗，AI Agent 与编码助手 +3
居首）。注意：分类以 catalog 的脚本分类器落位为准（协议：标签跟脚本走），
人工策展条目可能落位不同。

## 怎么跑
```bash
bun tools/2026-10-17-star-flow-weekly/star-flow-weekly.ts [--days 7]
```
退出码：0 = 正常（含零增量的空态输出）；1 = 数据缺失。

```
  ...
```
