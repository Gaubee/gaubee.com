# x-daily-backfill — X 日报缺口检测与补跑清单

## 是什么
扫描 events 目录，列出「日报制度起点（最早 x-daily）之后，有 x-archive 但缺 x-daily」
的日期，逐个给出差分运行日建议（报告日 +1，自动探测 changes 文件实际存在的最近日）
与可直接复制的补跑命令。

## 解决什么
2026-10-10 的 X 日报因媒体闸门顺延，10-09 缺口靠人记人补。本工具把「哪些日子欠日报、
怎么补」变成一条命令；cron 第 5 步之后跑一次即可兜底发现顺延缺口。

## 怎么跑
```bash
bun tools/2026-10-11-x-daily-backfill/x-daily-backfill.ts [--limit N]
```
退出码：0 = 无缺口；1 = 有缺口。口径：今天及未来日期不算缺口（未来任务）；
制度起点前的历史归档不算缺口。

## 真实示例输出（2026-10-11 实跑，当日上午补发 10-09 后）
```
无缺口：每个有互动的归档日都有对应 X 日报
（exit 0）
```
补发前运行会列出 `2026-10-09 → bun scripts/x-daily-events.ts --date 2026-10-09 --run-date 2026-10-10`。
