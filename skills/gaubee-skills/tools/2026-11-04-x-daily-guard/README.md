# x-daily-guard — X 日报归窗防线

## 是什么

发布前的硬门：读目标 X 日报里的推文 id，逐条核对它在**所有** x-daily / x-archive 报告与事件里出现的窗日期集合。出现两个以上窗即判违规，退出码 1。

## 解决什么

两起真实事故：

1. 2026-10-22 三连渲染，同一份差分被 `--force` 渲染进三个日报。
2. 2026-11-04 补跑，`x-daily-events.ts --date 2026-10-31` 给「当日无独立差分」的日期沿用了 11-03 那一批 15 条，生成了一份与 11-03 完全相同的日报（已当场删除）。

生成器是 fail-open 的，靠人眼盯不出来。本工具把归窗不变量变成可执行的门。

与既有工具的分工：`xd-window-audit`（10-23）按 changes 差分正向核对「每条捕捉在**同窗内**恰好出现一次」；本工具是反向的「这条推文**有没有跨窗**」。10-23 那个工具查不出跨窗重复——本工具首跑就抓到了 10-22 与 10-23 两窗之间的 2 条历史跨窗条目。

## 怎么跑

```bash
bun tools/2026-11-04-x-daily-guard/x-daily-guard.ts --date 2026-11-03
bun tools/2026-11-04-x-daily-guard/x-daily-guard.ts --file <路径>
```

## 真实示例输出（2026-11-04）

当窗干净（exit 0）：

```text
核对 2026-11-03-x.md：15 条推文，窗口索引 1332 天
OK：全部条目只在 2026-11-03 这一个窗内出现
```

历史已发布窗的跨窗重复（exit 1，作为反例保留不改）：

```text
核对 2026-10-22-x.md：16 条推文，窗口索引 1332 天
跨窗重复 2 条（归窗不变量：每条捕捉恰落一个窗）：
  - 2113299853359149360 除 2026-10-22 外还出现在 2026-10-23
  - 2113300317584720259 除 2026-10-22 外还出现在 2026-10-23
```

## 建议用法

放在 `publish.ts` 之前跑（发布链里当门），或补跑批里每生成一份 X 日报就立即跑一次——今天的 10-31 重复就是在这一步被拦下的。
