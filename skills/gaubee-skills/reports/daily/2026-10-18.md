# GitHub 日报：2026-10-18

2026-10-18 是站点基建日：修复了悬置两个月的登录断链、头像换上国内可达的自有代理域、视频播放器按 X 形态重写。公开侧 4 条提交全部在 gaubee.com；私有侧 5 仓 103 条提交只记提名。

## 站点基建三连（gaubee.com）

排查发现 auth.gaubee.com 自 8 月 15 日 gaubee.com 的 DNS 迁往阿里云后就全局失效：Workers 自定义域没了证书与路由，OAuth 登录中断两个月，会话未过期所以一直没察觉。三条提交分别收口三件事：其一，X 头像域迁到 twimg.tweb.xin（同账号存活 zone 挂自定义域，1315 个事件文件 6278 处 URL 重写，国内直连实测 0.35s 握手）；其二，登录与上传自托管：新组件 auth-server 以 bun 单二进制 + systemd + openresty 反代落在 gaubee-cloud 上，域名不变故 GitHub 回调与前端零改动，geo 媒体路由也首次真正落地；其三，配套的 openresty vhost 陷阱收据（server_name 抢占主站名的事故与回滚）。当日全部公网验收通过：OAuth 302、公网 200、TLS 0.1s。
