## 分析（agent 补充）

**这周的主线是「让 agent 真的能持续干活」。** keel 的触发器系统一周内落地：HMAC 签名的 webhook、有界的 catch-up 重放、并发上限、持久化游标，配三条测试守住 HTTP 并发下 goroutine 不崩、两次重放都能跑完。接着是运行时快照，把 configHash、anchorEventSeq、toolManifestHash 三个值落到 run.finished，清单哈希下沉到 agenttool 让 kernel 包不再反向依赖产品层。放置层开了首切片：groups 与 session_placement，带 lease、409 冲突与组槽位配额 429。这条线正好落在 profile 的「AI 重心在 agent 工程化」上，而且比收藏里的 agent 框架更靠底层——不是接 MCP，而是自己定义调度与配额。

**久点从能演示走到能运营。** TokenPlan 打通全模态，realtime 链路补韧性；任务派工看板从零建起，对讲机媒体密钥做成可配置，短信通道健康度显示在 compose 上；E2E 记录覆盖 wave5 回放缓存、共享栈串行化与采购审批复测。判据是「有看板、有健康度、有 E2E 证据」，这三样齐了才算能运营。

**OAR 与 keel-ga 两条验收线都收口。** OAR 让 Codex 的侧完成事件触发 turn 结束，同一 sidecar 的轮次串行化，加了可复现的冒烟命令；keel-ga 的 G5 全 PASS 并过交叉复核，验收脚本覆盖 1000/64 并发、20 次 SIGKILL、2GB cgroup 与公网报告。

**站点与管道这周处理的是「环境变化带来的假故障」。** 站点地址一周内换了两次（北京到香港再到新入口），写死的旧 IP 让 HLS 与部署冒烟连续三天报「媒体 404 / TLS 不可达」，实际只是钉子钉错了地址；现在入口 IP 走 DoH 动态解析。另外发现「迟到的收藏」（starred_at 是 11-19、11-21 才抓到）会让此后每天的累计都偏，补了检测与回补工具；译文批次残留在 /tmp 会被下次合并覆盖手工修过的内容，也补了归档。工具工坊本周落了 morning-brief、commit-workflow-groups、report-facts-check、taxonomy-coverage-audit、rename-similarity-audit、pipeline-facts、late-star-backfill、event-sync-check、site-endpoint-doctor、stale-out-guard 十个提案。

**兴趣漂移：从「agent 工具」转向「agent 造的东西」。** 本周收藏里 agent skills 占了 6 个（oh-my-pi、screen-relay、dsh-game-studio、cangjie-skill、seo-skills、appllama-skills），另有三个是「在不可能的地方跑内核」（iOS 上跑 Linux、Android 内核 root、浏览器里跑 Docker），两个流媒体服务器，以及 Linger 与 kinetic 这两个本地推理引擎。与前几周的「做工具」相比，这周重心偏到「用 agent 产出内容与技能」，X 侧同步被 undocker（浏览器里跑容器）、wland（浏览器里的 Wayland 合成器）、Linger 开源刷屏。

**漂移提醒：** 这周 56 项元数据变化里有相当一部分是改名（pgx→pgboxdb、electric-pglite→pglite、webrtc→libwebrtc），这类抖动不该当新增信号读；依赖侧新技术首见只有 esbuild 一项，采用节奏比星标数量看起来慢。
