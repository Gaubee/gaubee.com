# GitHub 日报：2026-10-06

10-06 分量最重的线在 Gaubee/openai-image-webui：22 条公开提交，仓库拆成双 UI 结构，重设计的 webapp 当天补齐图像编辑链路。公开侧合计 45 条提交：openai-image-webui 22 条，jixoai/openspecui 12 条，gaubee.com 6 条，cdn-media.gaubee.com 3 条，handicraft 2 条。

## openai-image-webui：fork 拆出双 UI 结构

上游原版与重设计版分层而居：src/ 保留 upstream-original，webapp/ 独立成应用。合并 upstream/main 之后 fork 恢复了自己的样式，index.css 迁到 Tailwind v4，service worker 只在生产注册；webapp 的无端口域名定名 openai-image-webapp.localhost，manifest 与图标改由自己提供。

## openai-image-webui：webapp 补齐图像编辑链路

图像编辑三步当天接通：参考图上直接画 inpainting 蒙版（自上游 MaskEditor 移植），生成图可一键转入编辑模式，参考图持久化进 IndexedDB 让「Reuse params」连原图一起带回。

输入与产出跟着修：下载改为真实文件，vision 输入改吃全分辨率图，默认视觉模型从 gpt-4.1-mini 换成 gpt-6-luna。

交互抛光一批：页面任意位置拖图即加输入，单次提交的产出改网格展示，预览支持方向键翻图并可就地下载，清空任务先确认，生成按钮不再被双滚动埋没，复用旧提示词时尺寸选择保持权威，素材库挂载后按实际列宽重排。
